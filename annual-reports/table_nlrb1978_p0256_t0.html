Reader’s notes

p. 256. Seven printed columns: stub, "Cases in which formal actions taken", then four under the spanner "Formal actions taken by type of case" plus the "Total formal actions taken" column, which sits inside that spanner. The column heads are letter-spaced in the scan ("R C", "R M", "R D"); transcribed as RC, RM, RD, UD. Arithmetic check (not applied to any cell, only used to confirm placement): in every data row the printed "Total formal actions taken" equals RC+RM+RD and excludes UD — e.g. "Hearings completed, total" 2,008+76+207 = 2,291 as printed, while adding UD 5 would give 2,296. This is consistent throughout the table, so it appears to be how the column was defined rather than a misprint. All subtotals also reconcile (1,959+148 = 2,107; 99+572+5 = 676; 35+23+39 = 97; 78+19 = 97), which corroborates the digits read. "Review of regional directors' decisions" (printed with the end-of-line break "de-cisions"), "Regional directors' decisions" and "Outcome" are label-only section lines with no values. The RD cell of "Hearings on objections and/or challenges" is faint in the scan but reads 16, confirmed by the column (191+16 = 207) and row (258+9+16 = 283) sums. The UD cells of the first two rows print in a slightly smaller face in the scan; they are values (5), not footnote markers. The caption carries footnote marker 1 and is excluded per instructions.
