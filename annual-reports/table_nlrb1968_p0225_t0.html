Reader’s notes

p. 225. Crop is a partial table: it ends immediately after the "Contested" row with a column rule, so the remaining body rows (and the footnote block) are not on this image. The caption carries a footnote marker 1 and the body references a footnote 2, but no footnote text is printed in the crop, so `footnotes` is empty. Decimal points: this 300-ppi bitonal scan drops or thins many decimal points in the percent columns, so values print as e.g. "100 0", "25 1", "47 4", "0 6". These are the same glyph that reproduces cleanly elsewhere in the same column (e.g. CA "100.0", "18.4"), so every percent value has been transcribed with its decimal point. No digits were altered. CD cases / Number, row "Before issuance of complaint": the cell holds a parenthesised raised 2 and no numeral; transcribed as "(^2)". The CD "Percent of total closed" cell in that row is a dash rule, hence "". Note the component CA+CB+CC+CE+CP numbers in that row sum exactly to the printed All C figure of 3,367, implying a CD value of 0, so the footnote reference appears to stand in for a zero (transcribed as printed, not corrected). Blank-looking cells: in several rows the "percent" cell is a dash rule and in a few it is simply empty; both are rendered as "" per instruction, so the two cannot be distinguished in the grid. Row label "Formal settlement" is followed by a small stray mark (a damaged colon or the first leader dot) before the leader dots; it was dropped as a leader artifact. All printed All C "Number" totals cross-check against the sum of the six case-type Number columns in every data row, which supports the column assignment.

p. 226. Continuation page: no column headings are printed on this crop, so header_rows is empty. The grid has 16 columns, counted from the column rules: the stub, then a three-column total block (number, percent of all cases, percent of the disposition category), then six two-column case-type blocks (number, percent) — on the heading page these are the CA/CB/CC/CD/CE/CP columns, but nothing on this image names them, so no headings were reconstructed. Column alignment was checked arithmetically: in every data row the six case-type counts sum exactly to the total-number cell (e.g. Withdrawal 4,244+1,386+459+2+10+161 = 6,262; Dismissal 3,694+1,510+229+1+18+176 = 5,628), and the sub-rows under Withdrawal and Dismissal sum exactly to their category lines in both the count and the percent columns. No discrepancy or suspected misprint was found. Decimal points: this is a coarse 1-bit scan and the period in the one-decimal percent cells frequently failed to reproduce, printing as a gap (\"2 5\", \"35 2\", \"0 4\"). The period does survive in many cells of the same columns (1.9, 33.6, 34.2, 97.1, 100.0, 27.0, 31.7, 95.1, 40.6, 35.4, 0.2, 0.0), confirming the typesetting, so the decimal point is written in every percent cell. The count columns are integers and carry no decimal point. The cells transcribed as \"(^2)\" (the fifth case-type block, rows \"Before issuance of complaint\" under both Withdrawal and Dismissal) are printed as a parenthesised raised 2 — a footnote reference standing in place of a value, not a quantity; the caret marks the raised digit. The row \"10(k) actions (see table 7A for details of dispositions)\" carries values only in the total-number, total-percent and fifth-case-type columns; all its other cells are dash rules. The \"Otherwise\" row's third column is likewise a dash rule. The vertical string \"348-205—69——15\" down the left edge is a printer's signature mark in the gutter, not table content, and is excluded. Footnote marker 1 does not appear anywhere in the body on this crop; it belongs to the caption carried on the preceding page.
