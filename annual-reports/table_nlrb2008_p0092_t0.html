p. 92. 17 columns: stub, "All cases", eight unfair-labor-practice columns (All C cases, CA, CB, CC, CD, CE, CG, CP), four representation columns (All R cases, RC, RM, RD), and three single columns UD, AC, UC. The last three columns have a two-level heading (the wrapped name over the code), so the code line is the third header level; the other headings span all three levels and are repeated. The caption marks the table as "Page 1 of 5", so the table continues beyond this crop; no footnote text is printed on this page, although footnote markers are referenced (caption "Fiscal Year 2008^1" — caption excluded per instructions — and the stub heading "Industrial Group^2"). Note that "31-Manufacturing" and "32-Manufacturing" are subtotal lines as printed; the 32-Manufacturing block ends at a double rule at the bottom of the crop. Every printed subtotal row I checked reconciles with its component rows and with the row-wise column sums (All C = CA+CB+CC+CD+CE+CG+CP; All R = RC+RM+RD; All cases = All C + All R + UD + AC + UC), so no misprints are suspected. Unusual but clearly printed: "Plastics and Rubber Products Manufacturing" has CA 107 and CB 116 (CB larger than CA), which is consistent with its All C total of 223.

p. 93. 17 columns: stub plus "All cases", eight unfair-labor-practice columns (All C cases, CA, CB, CC, CD, CE, CG, CP), four representation columns (All R cases, RC, RM, RD), and UD, AC, UC. The last three column headings are printed in two tiers (the spelled-out name above a rule, the two-letter code below), so they are repeated across the three heading levels; "Industrial Group^2" and "All cases" are tall single headings repeated in every level as well. This is a continuation page (caption reads "Page 2 of 5"): the table begins before this crop and continues after it. The last body row, "Air Transportation", sits immediately above the bottom edge and later rows plus any footnote block are cut off, so no footnotes are printed on this image even though superscript markers 1 (caption) and 2 (stub heading) appear. The indented subtotal line transcribed as "Wholesale Trade" is printed without a numeric sector prefix, unlike the other subtotal lines on the page ("33-Manufacturing", "44-Retail Trade", "45-Retail Trade"); it appears to be a typesetting omission of "42-" but is transcribed exactly as printed. All arithmetic was checked and is internally consistent as transcribed: in every data row CA+CB+CC+CD+CE+CG+CP equals "All C cases", RC+RM+RD equals "All R cases", and All C + All R + UD + AC + UC equals "All cases"; each of the four subtotal lines equals the sum of its member rows in every column. No cell was illegible or doubtful.
