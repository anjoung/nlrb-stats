Reader’s notes

p. 195. Structure: this is one table with a single shared stub and 11 printed columns — five "Number of unfair labor practice cases" columns and five "Number of representation cases" columns, with the same stub label serving both halves of each printed line. It is not a two-panel layout (there is only one row-label column), so the left- and right-hand values on each printed line are correctly paired on one grid row. Banner rows: three unlabelled-stub band headers are printed across the body ("CA cases 1" over the ULP columns with "RC cases 1" over the representation columns; likewise "CB cases 1"/"RM cases 1" and "CC cases 1"/"RD cases 1"). Because each banner is a spanning label over data columns rather than a stub label, I repeated each banner in every column it spans and left the stub cell empty. Footnote markers: every banner carries a raised "1", but no footnote text is printed within this crop, so `footnotes` is empty — the note text presumably falls below the crop or on a later page. Crop: the table is cut off after the CC/RD band at a horizontal rule; further case-type bands (e.g. CD/CE, UD) and the footnote block are not on this image. Doubtful cells: in row "Pending June 30, 1960" of the CC band, "Unaffiliated unions" has a small stray scanner mark immediately left of the digit (reads like "ɔ 6"); I transcribed it as 6, which the row sum confirms (7+6+8+367 = 388). The "Total" heading cell of the unfair-labor-practice half carries a small stray speck above it, not a footnote marker. RM "Received fiscal 1960" (728) and RD "Closed fiscal 1960" Individuals (596) are slightly broken in the scan but are confirmed arithmetically. Blank cells: the RC "Employers" column is a dash rule on all five rows, and the RM "AFL-CIO affiliates", "Unaffiliated unions" and "Individuals" columns are dash rules on all five rows; all are transcribed as "". Arithmetic: every printed row total equals the sum of its components, and in each band On docket = Pending July 1 + Received, and Pending June 30 = On docket − Closed. No misprints detected.

p. 196. No column headings are printed on this crop — the table continues from the preceding page — so header_rows is empty; nothing was reconstructed. Column count was taken from the rules: the horizontal rules of every block run the full page width, from the stub rule to the far right edge, and enclose five data columns to the left of a double vertical rule plus five further ruled columns to its right. Those five right-hand columns are completely empty in all three blocks on this page (no figures, no dashes), so they are transcribed as empty cells; this keeps the five printed figures of each row in columns 1-5, where they are printed. A reader who treats the empty right-hand half as not belonging to this table can drop the last five cells of every row without affecting any value. The three centred block labels (CD cases, CE cases, CP cases) sit over the left-hand data columns and head row groups rather than labelling columns, so they are given as section rows with no values; each carries a raised 1 footnote marker. In the CE and CP blocks the "Pending July 1, 1959" line carries a dash rule across the data columns instead of figures, so its cells are empty, and the four figure lines in those blocks belong to Received / On docket / Closed / Pending June 30; the arithmetic confirms this reading (CE: 0 + 26 = 26 on docket, 26 - 15 = 11 pending; CP: 0 + 273 = 273, 273 - 184 = 89). Every block cross-checks: the four component columns sum to the first column in each row, and pending + received = on docket, on docket - closed = pending in each column. Nothing is cut off by the crop; the page's running head (Appendix A) and page number (179) are printed sideways at the right edge and are excluded, as is the blank lower half of the page.
