Reader’s notes

p. 136. Six printed columns: stub, "Cases in which formal actions taken", then the spanner "Formal actions taken by type of case" over "Total formal actions taken^2", RC, RM, RD and UD (UD is set off by a double rule but is a column of the same spanner). The stub heading and the "Cases in which formal actions taken" heading each span both heading levels, so they are repeated in both. "Review of Regional Directors' decisions:", "Regional Directors' decisions." and "Outcome:" are label-only section lines; their value cells are blank in the image. "Regional Directors' decisions." is printed with a terminal period where a colon would be expected (probably a broken colon in the scan); transcribed as printed. Two labels wrap in the original and were joined: "Transferred by Regional Directors for initial deci-/sion" and "Withdrawn after request granted, before/Board review". Scan quality: the page is a 1-bit scan in which the digit 1 is often set as a short "l"-like glyph and the letter i frequently loses its dot ("actions", "Initial", "Decisions"); readings were taken from context and column arithmetic. All internal sums check out (e.g. 952 = 782 + 170; 916 = 752 + 164; 761 = 710 + 51; 283 = 263 + 6 + 14; 48 = 43 + 2 + 3), which supports the digit readings. Note that the "Total formal actions taken" column excludes UD counts per footnote 2, so RC + RM + RD equals that column and UD stands apart. Under "Outcome:" the label is "Election directed" (singular) whereas elsewhere it is "Elections directed"; kept as printed. The caption and its footnote marker (Fiscal Year 1995^1) were excluded as instructed.

p. 137. Seven printed columns: stub, "Cases in which formal actions taken" (spans both heading levels), and five columns under the spanner "Formal actions taken by type of case". The crop is a continuation page ("—Continued"); the table's earlier rows are on the preceding page. Scan artifacts, resolved to the obvious intended spelling: the 1-bit scan drops the dots on many "i" characters ("objectıons", "Regıonal", "stıpulated", "Decısıons", etc.), and "before" in "Withdrawn after request granted, before Board review" prints as "bcfore". These are rendered as normal English spellings. Row-label wrapping joined into single labels: "In directed elections (after transfer by Regional Director)" (two lines; a stray period follows "Director)" before the leader dots) and "Withdrawn after request granted, before Board review" (two lines). Two section lines carry a label and no values: "Review of Regional Directors' supplemental decisions:" and "Regional Directors' decisions:". Arithmetic observations (transcribed as printed, not corrected): in "Decisions on objections and/or challenges, total", 413+2+48+6 = 469 against a printed total of 463, and footnote 2 says UD case counts are not included in the "Total formal actions taken" column, so 413+2+48 = 463 is consistent. Similar UD-exclusion arithmetic holds on the other rows (e.g. "By Board": 361+1+42 = 404). The "Remanded" row reads 1 / 1 / 0 / 0 / 1 / 0, with the 1 in the RD column and 0 in RC; this is as printed.
