Reader’s notes

p. 225. 16 columns: stub + All cases + 7 unfair-labor-practice columns (All C cases, CA, CB, CC, CD, CE, CP) + 4 representation columns (All R cases, RC, RM, RD) + UD, AC, UC. The crop ends immediately after the "Mining" subtotal line (a double rule follows), so the table continues on the next page; no footnote text is visible in the crop even though the caption carries a raised 1 and the stub heading "Industrial group" carries a raised 2. The caption's marker is not transcribed, per instructions; the stub marker is kept as "Industrial group^2". Digit legibility: this scan degrades the numeral 3 so that it can read as 8. I resolved the doubtful cells by checking every row (detail columns against All C cases / All R cases / All cases) and every one of the 15 numeric columns against the "Manufacturing" and "Mining" subtotals; after the readings below, all 28 rows and all 15 columns reconcile exactly, which is why I read these as 3 rather than 8: Textile mill products / CA = 300; Paper and allied products / CA = 243 and / CP = 3; Rubber and miscellaneous plastic products / All R cases = 360; Fabricated metal products / CB = 309; Machinery (except electrical) / CC = 38; Professional, scientific, and controlling instruments / RC = 93; Miscellaneous manufacturing industries / RC = 300; Manufacturing / All R cases = 6,361. These eight cells are the least certain in the grid; every other cell is clearly printed. No value is computed or altered beyond that glyph disambiguation, and no printed total disagrees with its parts. "Miscellaneous manufacturing industries" / All cases has an ink speck before the first digit; the value is 996.

p. 226. Continuation page: no column headings are printed on this crop, so header_rows is empty. The grid has 16 columns (stub + 15 numeric); the earlier rows of the table and its caption are on the preceding page. Suspected misprint: in the "Services" subtotal row, column 13 is printed as a single-digit "3", but the twelve service rows above it sum to 31 in that column (4+1+4+1+15+0+0+5+1+0+0+0). Transcribed as printed. Every other column of the "Services" subtotal and every column of the "Transportation, communication, and other utilities" subtotal reproduce exactly from the detail rows above them, which supports the column assignment throughout. In the "Local and suburban transit and interurban highway passenger transportation" row, column 13, the value 6 carries a small stray tick above it in the scan; it is scanning debris, not a footnote marker — the subtotal (23 = 6+7+2+3+3+2) confirms the value is 6. A few other faint specks appear beside values ("Other transportation" column 8, "Museums..." column 5, "Communication" column 7) and are likewise treated as scan noise, not markers. Horizontal rules separate three blocks (manufacturing/trade industries continued, transportation group, services group); these are rules, not labelled rows, so no empty section lines were inserted.
