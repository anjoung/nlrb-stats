Reader’s notes

p. 124. The crop is cut off at the bottom: the "Construction" row is the last line visible and its bottom half is clipped by the crop edge, and the table clearly continues below (further industry divisions and a grand total). No footnote texts are visible in the crop, so `footnotes` is empty even though markers ^1 (on the caption, omitted per instructions) and ^2 (on the stub heading "Industrial group") are printed. Header structure: 17 columns. The stub, "All cases", and the twelve C/R case columns occupy one tall header cell each and are repeated down all three levels; only the last three columns are subdivided, with "Union deauthorization cases"/"Amendment of certification cases"/"Unit clarification cases" over the sub-labels UD/AC/UC. The scan carries scattered specks that sit next to digits without being part of them: a stray comma-like mark under "Industrial group^2" in the stub heading; a dot before "1" in Tobacco manufacturers / RD; a dot after "0" in Textile mill products / RM; a dot before "7" in Stone, clay, glass, and concrete products / CC; a dot before "897" in Fabricated metal products / All C cases; an apostrophe-like mark after "0" in Mining / CD. All are read as the plain digits transcribed. Arithmetic check (not applied to the cells, only used to confirm column placement): every one of the 16 data columns sums across the 22 manufacturing industry rows exactly to the printed "Manufacturing" subtotal, and across the 4 mining rows exactly to the printed "Mining" subtotal; each row's C + R + UD + AC + UC components also sum to its printed "All cases" figure, and its CA...CP to "All C cases" and RC+RM+RD to "All R cases". No printed value appears to be a misprint.

p. 125. This page is a "—Continued" portion of Table 5, so the industrial groups printed before "Wholesale trade" (and any heading rows for earlier divisions) appear on the preceding page and are not in this crop; no section label rows are printed on this page, only horizontal rules separating the divisions. Column structure: 17 columns — stub, "All cases", eight unfair-labor-practice columns (All C cases, CA, CB, CC, CD, CE, CG, CP), four representation columns (All R cases, RC, RM, RD), then UD, AC and UC. The last three columns each carry a two-part heading (spelled-out name above, code letters below), which is why three header levels are given. The stub heading carries footnote marker 2 ("Industrial group^2"); the footnote-1 marker is attached to the caption year (excluded per instructions) but its text is printed below the table and is included. Indentation in the stub distinguishes division totals (Wholesale trade, Retail trade, Finance/insurance/real estate, U.S. Postal Service, Transportation/communication/other utilities, Services, Public administration, Total) from the component industry lines, which are set flush left; this has been preserved only in wording, not in leading spaces. All printed row and column totals check out arithmetically (every component row sums to its All C / All R / All cases figure, and each subtotal equals the sum of its components), so no misprints are suspected. The only unusual-looking value, CG = 29 for Health services (and the identical 29 in the Services subtotal and grand total), is as printed and is consistent with the row sums.
