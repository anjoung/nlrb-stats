Reader’s notes

p. 173. Grid is 11 columns: one stub plus five unfair-labor-practice columns (Total, AFL-CIO affiliates, Unaffiliated unions, Individuals, Employers) and five representation columns with the same five labels. There is a single stub column at the far left, shared by both halves, so this is not a two-panel layout. The four case-type band labels (CA/RC, CB/RM, CC/RD, CD) are printed as centered rules across the column groups, not in the stub. I transcribed each as a label row with the band label repeated in every column it spans and the stub cell left empty, following the spanning convention used for headings. In the CD band there is no representation-case counterpart, so the right-hand five columns of that label row and of its five data rows are blank in the original. The stub has no printed heading; the top-left header cell is empty (a stray ink mark sits there). In the RC band, row "Pending July 1, 1958", column "AFL-CIO affiliates" (representation side), the value is printed as "1 012" with the thousands comma faint or dropped by the press; transcribed as 1,012, which the printed row total of 1,435 (1,012 + 422 + 1) confirms. Cells rendered as dash rules (------) are blank in the source and transcribed as empty: the representation "Employers" column throughout the RC and RD bands, and the three representation union/individual columns throughout the RM band. Every column sum in all four bands agrees with its printed total, and "On docket" equals "Pending July 1" plus "Received" in each case; no misprints detected. The footnote line is damaged in the scan and reads "See table 1,r ootnote 1" where a broken "footnote" belongs; transcribed as "footnote". The line carries no terminal period.
