p. 264. Structure: 23 columns — stub, two total columns, then five outcome groups (Affirmed in full; Modified; Remanded in full; Affirmed in part and remanded in part; Set aside), each with Fiscal Year 1973 Number/Percent and Cumulative fiscal years 1968-1972 Number/Percent. Three heading levels. Decimal points: this is a 1-bit scan in which the period in many percent cells did not reproduce, so they print as a bare space (e.g. "16 0", "4 5", "82 4", "7 9"). Every percent column in the table is one decimal place, so these have been transcribed with the decimal point restored ("16.0", "4.5", "82.4", "7.9"). No digits were altered. The same dropout affects periods in row labels and abbreviations (e.g. "Denver, Colo", "Washington, D C", "New York, N. Y."); standard punctuation has been written ("Denver, Colo.", "Washington, D.C.", "New York, N.Y.") and the row numbers are given uniformly as "1." … "10." although the period after the numeral is visible on only some lines. The Washington, D.C. row carries no circuit number in the stub, as printed. Arithmetic verification: all eleven circuit rows sum to the printed "Total all circuits" line in every one of the 22 numeric columns, and every row's five outcome Number cells sum to that row's two Total columns. All 24 checks balance, which corroborates the digits and their column assignment. Doubtful cells: (a) Cincinnati, Ohio, Modified / Fiscal Year 1973 / Percent reads "12.2"; 7 of 58 is 12.07 percent, so the printed value appears to be a misprint for 12.1 (or possibly 12.0). Transcribed as printed. (b) Washington, D.C., Set aside / Cumulative fiscal years 1968-1972 / Percent reads "4.3"; 5 of 118 is 4.24 percent, and this table truncates elsewhere (e.g. Richmond 13/15 printed as 86.6), so 4.2 would be expected. Transcribed as printed. (c) Stray ink specks sit immediately left of three values — the "1" in Boston / Set aside / FY 1973 / Number, the "20" in New York / Modified / Cumulative / Number, and the "27" in Washington, D.C. / Total fiscal year 1973. These are leader-dot or speckle artifacts, not digits or footnote markers; all three values are confirmed by the column and row sums.
