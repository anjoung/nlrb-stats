These are clearly degraded decimal points (every one is a one-decimal percentage consistent with its column) and have been transcribed with the point restored. "Total number of cases closed", All C cases / Percent of total method: printed as "0.0". This is anomalous — that column is a within-method percentage and the cell is normally blank on the total line — but it is transcribed as printed. "Before issuance of complaint", CD cases / Number: the cell holds a parenthesised raised digit rather than a value, transcribed as "(^2)"; the raised character is most likely a 2 but the resolution leaves some doubt (it could be a 3). Column arithmetic implies the underlying value is 0, since CD informal settlement = 2 = 0 + 1 + 1. Rounding conventions differ between columns in the original: the three All C columns round to the nearest tenth (e.g. 2,421/29,910 = 8.094 printed as 8.1; 798/29,910 = 2.668 printed as 2.7), while every CA–CP "Percent of total closed" column truncates (e.g. 7,280/20,987 = 34.688 printed as 34.6; 9/21 = 42.857 printed as 42.8). Nothing has been recomputed; these checks were used only to confirm the digits read. Dash rules ("——") in percent cells are transcribed as empty strings, per instruction. All number columns were cross-checked against their subtotals and all sum correctly.
