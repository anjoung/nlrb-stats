p. 117. The table is cut off at the bottom of the crop: it continues past "Petroleum and Coal Products Manufacturing" on the next page (no subtotal row for the 32-/33-Manufacturing groups is shown, and the industry list plainly continues). A second footnote marker (a superscript "2", presumably keyed to the stub heading "Industrial Group^2") is just visible at the very bottom edge below footnote 1, but its text is cut off by the crop, so it is not included in `footnotes`. Digit-grouping commas are printed inconsistently and have been transcribed exactly as they appear: in the "All C cases" and "All R cases" columns the four-digit figures are set without a comma (1907, 2519, 1157, 1442, 1032), while the adjacent "All cases", "CA" and "RC" columns do use commas (3,069 / 3,970 / 1,190; 1,375 / 1,717; 1,101 / 1,380). This is a typesetting quirk of the source, not a reading error. Row labels for the group subtotals (Agriculture, Forestry, Fishing, and Hunting; Mining; Construction; 31-Manufacturing) and for Utilities are printed indented relative to the detail lines and are set off by heavier rules; the indentation is not reproduced in the cell text. "31-Manufacturing" is printed exactly so, with the leading NAICS sector number. All printed row totals are internally consistent (each "All C cases" equals the sum of CA..CP, each "All R cases" equals RC+RM+RD, and "All cases" equals All C + All R + UD + AC + UC), so no suspected misprints among the values. No cells were illegible.
