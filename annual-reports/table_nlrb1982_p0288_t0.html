Reader’s notes

p. 288. The crop ends after the Tennessee row: the Region IV total line and all later regions (V onward) are cut off, as is any footnote text. Footnote markers are visible on the caption (1) and on the stub heading "Standard Federal Regions 2", but the footnote texts themselves are not printed within this crop, so `footnotes` is empty. Header structure: three printed tiers. "Unfair labor practice cases" spans the eight columns All C cases through CP; "Representation cases" spans All R cases through RD. The stub heading, "All cases", and the eight/four code columns are tall headings repeated down the levels; the third tier carries only the code letters UD, AC and UC under the three tall right-hand headings "Union deauthorization cases", "Amendment of certification cases" and "Unit clarification cases". The West Virginia row has a stray ink dot immediately left of the CE value; the printed value is 0. Minor stray specks also sit in the blank margin beside the New York, Puerto Rico and Mississippi rows and left of the stub heading; none are footnote markers or digits. Arithmetic cross-checks: every state row's CA+CB+CC+CD+CE+CG+CP equals its "All C cases", RC+RM+RD equals "All R cases", and All C + All R + UD + AC + UC equals "All cases". The three region totals also equal the sums of their member states in every column. No misprints detected.

p. 289. 17 columns: stub, All cases, eight ULP columns (All C cases, CA, CB, CC, CD, CE, CG, CP), four representation columns (All R cases, RC, RM, RD), then UD, AC and UC. The three right-hand headings are two-level (e.g. "Union deauthorization cases" over "UD"); the ULP/representation sub-headings and "All cases" are repeated into the third level because their boxes run the full depth of the heading band. Doubtful cell: Michigan, column RC. The glyph reads as 761 in this scan and is transcribed as printed, but it is almost certainly a degraded 261: Michigan's All R is 418 (= 261 + 18 + 139), and the Region V RC total of 1,175 less the other five states (317 + 107 + 121 + 255 + 114 = 914) leaves exactly 261. Treat the printed leading digit as uncertain. Utah, column CE: a short stray mark (dash or leader-dot remnant) sits just left of the 2; transcribed as 2. Every other row and column cross-foots exactly against its printed totals (state rows sum to Region V, VI, VII and VIII; component columns sum to All C cases, All R cases and All cases), which supports the digit reading throughout. This is a continuation page: the "Region IV" line is a regional total whose state rows are printed on the preceding page, and no footnote text appears in the crop (the markers on the caption and on "Standard Federal Regions" refer to notes printed elsewhere in the table). Below the Region VIII line the crop ends at a partial rule, so the table continues past the bottom of this image.

p. 290. Stub column absent: this crop is the right-hand (continuation) half of a table printed across facing pages, so it carries only numeric columns — no row labels and no column headings appear anywhere on the image. Accordingly header_rows is empty and cell 0 of each row is the leftmost PRINTED column (the one beginning 811 / 6,348), not a stub. Row labels for these 12 rows must be taken from the facing page. Column count: 16, read off the vertical column rules; every row has a value in all 16, so no empty cells arise. Rule structure (not transcribed as rows): a single horizontal rule separates row 5 (470 ...) from the total row 7,928 ...; a double rule separates that total from row 7 (303 ...); a single rule separates row 10 (1,486 ...) from the subtotal 2,502 ...; and a rule separates that from the final grand-total row 47,210 .... So rows 6, 11 and 12 of the grid are total/subtotal/grand-total lines. Arithmetic check: all 16 columns of both blocks foot exactly to their printed totals (e.g. 811+6,348+293+6+470=7,928; 303+153+560+1,486=2,502), so no misprint is suspected and column alignment is confirmed by the sums. Doubtful glyphs, all resolved by the column sums: in the total row (grid row 6) column 12 is printed with a broken "3" that looks like "2S2"; it is 232 (22+202+1+1+6=232). Likewise grid row 3 column 4 prints a degraded "38" (173+1,096+38+0+93=1,400) and grid row 2 column 5 a degraded "307" (21+307+5+0+12=345). In the subtotal row (grid row 11) there is a small ink speck just left of the value in column 15; the value itself is 0 (that column sums 0+0+0+0=0) and the speck is a scan artifact, not a digit, comma or footnote marker. No footnotes, caption, "—Continued" line, running head or page number fall inside the crop; the bottom rule of the table is visible, so the table ends at the 47,210 row.
