Verification: every state row was checked against its own All C / All R subtotals and its All cases total, and every column was checked against the four printed division subtotals (New England, Middle Atlantic, East North Central, West North Central). All of these balance exactly, with the two exceptions noted below. (1) Virginia, unfair-labor-practice columns: as printed, CA 283 + CB 97 + CC 8 + CD 1 + CE 1 + CG 0 + CP 0 = 390, one more than the printed All C cases figure of 389. Virginia's All cases (524 = 389 + 132 + 0 + 1 + 2) is internally consistent, so the discrepancy sits inside the C breakdown. Because the South Atlantic division subtotal is cut off by the crop, there is no column check to say which of CC, CD or CE is at fault, so the cells are transcribed exactly as read; treat Virginia CD and CE as doubtful. (2) Vermont, UD column: transcribed as 0. The glyph is small and sits in a region of this scan where the right-hand columns drift vertically relative to their row, and on inspection it could plausibly be read as 1. I read it as 0 on that basis; flagging it so it can be re-checked against the original page.
