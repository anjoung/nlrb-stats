Reader’s notes

p. 278. Seven printed columns: stub, "Cases in which formal actions taken", then the five columns under "Formal actions taken by type of case" (Total formal actions taken, RC, RM, RD, UD). A double vertical rule is printed between the RD and UD columns; it is a divider, not an extra column, so no empty column was inserted there. Consistency check (not a transcription change): the "Total formal actions taken" column equals RC + RM + RD on every row and excludes UD — e.g. 1,087 + 92 + 195 = 1,374 while UD is 7. This holds for all 24 data rows, which supports the column assignment as transcribed. Row "Dismissals on record" (under "By regional directors"): the RD cell is a printed zero, "0", not a blank or a dash; it is consistent with 105 + 24 + 0 = 129. Row "Granted": the RD cell is printed with a slightly malformed numeral that reads as "1" (it resembles a lowercase "l" in the scan); 13 + 0 + 1 = 14 confirms "1". Three rows carry a label and no values: "Review of regional directors' decisions" (printed over two lines, hyphenated "deci- sions", joined here), "Regional directors' decisions", and "Outcome". Wrapped labels joined into one line: "Transferred by regional directors for initial decision", "Withdrawn before request ruled upon", "Board action on request ruled upon, total", "Withdrawn after request granted, before Board review" (end-of-line hyphen in "grant- ed" repaired). Stray scanner artifacts appear in the left margin beside "Denied" (a small tick) and beside "Board decision after review, total" (a small dot); they are not footnote markers and are not transcribed. The only footnote marker on the page is the raised 1 in the caption, which is excluded per instructions, and its text is given in footnotes.

p. 279. Continuation page of Table 3B ("—Contd."), but the column headings are reprinted here, so they are transcribed. Seven columns: stub, "Cases in which formal actions taken", and five columns under the spanner "Formal actions taken by type of case" (Total formal actions taken, RC, RM, RD, UD). A double vertical rule separates the RD and UD columns; it is only a rule, not an extra column. Two rows carry a label and no figures: "Review of regional directors' supplemental decisions" and "Regional directors' decisions"; their value cells are left empty as printed. Arithmetic oddity transcribed as printed, not corrected: under "Cases in which formal actions taken", "Board action on request ruled upon, total" is 68 while the two preceding lines ("Request for review received" 58, "Withdrawn before request ruled upon" 1) sum to 59; the 68 does equal its own components (Granted 13 + Denied 55). Likewise in the "Total formal actions taken" column the total 60 equals 13 + 47. The scan is a coarse 1-bit image in which "i" dots are largely lost (e.g. "Decisions", "objections", "regional directors'"); spellings have been restored to the obvious words. No digit was doubtful: the only characters needing care were the "1" in the "Denied" UD cell and in "Board action on request ruled upon, total" UD cell, both read as 1.
