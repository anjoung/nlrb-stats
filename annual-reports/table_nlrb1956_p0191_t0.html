Decimal points: this 1-bit scan drops most decimal points in the percent columns, so values print as a digit gap ("100 0", "17 3"). Where the gap is unambiguous I have restored the point ("100.0", "17.3"), and where a lone fractional digit is right-aligned in a percent column I have restored the leading point (".7", ".4", ".6"); the same columns show the point rendered in other rows (3.7, 2.5, .4, .7, .5), confirming it is printed.
