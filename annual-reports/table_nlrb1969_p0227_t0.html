Reader’s notes

p. 227. Structure: 17 columns = stub + four panels (All R, RC, RM, RD) of 4 columns each. "Elections conducted" is centered over all four columns of each panel, so it is repeated 16 times in header level 2; the stub heading "Type of election" spans all three header levels. No footnotes are printed under the table. Blank-looking cells: in every "Rerun required" / "Runoff required" line the inapplicable cells are filled with dash rules ("---" or "--"), transcribed as "" per instruction; only the "Resulting in a rerun or runoff" column of each panel carries a value on those lines. Two cells where the printed figure disagrees with the table's own arithmetic, transcribed exactly as read: 1. Row "Rerun required" under "All types", column "Resulting in a rerun or runoff" of the RM panel: read as "0". The RM rerun entries below it (Stipulated 5, Regional director-directed 1) sum to 6, and the "All types" RM "Resulting in a rerun or runoff" cell is 6 (= 6 rerun + 0 runoff). A "6" is therefore expected here; at this scan resolution the glyph reads as a closed oval like the "0" on the "Runoff required" line directly beneath it, so 0/6 cannot be settled from the image. Treat this cell as doubtful. 2. Row "All types", last column ("Resulting in certification", RD panel): read as "298". Both the row (298 total = 1 + 4 + 293) and the column (93 + 126 + 73 + 1 + 0 = 293) imply 293, so either the original is misprinted or the third digit is a "3" that I have read as "8". Treat this cell as doubtful. The RD "Total elections" figure of 298 in the same row is corroborated (8,416 = 7,727 + 391 + 298) and is not in doubt. All other cross-checks pass: every panel's "All types" row equals the sum of its five type rows in all four columns, each panel's row identity (total = withdrawn + rerun/runoff + certification) holds, and the rerun+runoff splits sum to the "Resulting in a rerun or runoff" figures everywhere except the RM "All types" cell noted above. Row labels printed with leader dots have had the dots dropped. "Expedited—Sec. 8(b)(7)(C)" is printed with spacing as "Expedited—Sec. 8 (b) (7) (C)"; spacing inside the citation has been closed up.
