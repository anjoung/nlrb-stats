p. 240. Decimal points: this is a 1-bit scan in which the decimal point of most percent values has dropped out, so the page shows e.g. "100 0", "72 3", "21 1" with a gap where the point belongs. The point does survive in scattered cells of the same columns (".0", ".2", "21.9", "12.7", "1.1", ".8", "5.5"), confirming every percent column is printed to one decimal. I have therefore written the point in each such cell (100.0, 72.3, 21.1) rather than reproducing the gap as a space; no digit was changed, added or dropped. Cells printed with a bare leading point (".2", ".5", ".0") are kept in that form. Column totals: every number column cross-foots exactly (NLRA R + RC + RM + RD = All R) on all 29 rows, which is strong corroboration that each value sits under the right column. Doubtful small glyphs, all in percent columns: - "Before hearing", RC cases percent: read as 3.7; 281/7,719 = 3.64, so either the figure is a rounding/misprint or the final digit is a 6. The glyph matches the 7 in the All R cell of the same row. - "Recognition" (the row under "After hearing"), All R cases percent: read as .1, but 2/8,761 is well under 0.1 percent, where the table elsewhere prints the footnote mark "(2)" — as it does in the RC column of this very row. The cell may be "(2)" set small rather than ".1". - "Dismissed" (the row under "Before hearing"), RD cases percent: read as .9; 3/361 = 0.83, so this may be .8. - "Recognition" (the row under "Before hearing"), All R cases percent: read as .2; 22/8,761 = 0.25, which the table would round to .3 (as the RC column of the same row does). Other readings: "Before formal action, total" under RC cases is 5,664 — the last digit is lightly inked but is a 4, and it is what makes the row cross-foot to 6,336. Footnote markers printed to the left of their values are written after the value behind a caret: "3 87" is 87^3, "3 72" is 72^3, "5 87" is 87^5. The All R "Withdrawn" figure under "After Board decision" carries two raised marks, 4 and 5, written as 95^4^5. The "(2)" cells are the footnote mark used as a value ("Less than 0.1 percent") and are transcribed as printed. Footnote 1 is printed without a closing period.
