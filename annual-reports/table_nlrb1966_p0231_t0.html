Decimal points: this 1-bit scan drops most decimal points in the percent columns, so values print as e.g. "23 8", "100 0" (a few, such as "1.7", "1.1", "7.2", "0.6", "100.0", retain a visible dot). All such cells are transcribed with the decimal point, since the columns are percentages and the surviving dots confirm the typography; no digits were changed. Section line: the header band reads "A CERTIFICATION ELECTIONS (RC & RM)"; the period after "A" is not legible at this resolution and has been supplied by analogy with the surviving dots elsewhere. Only panel A appears in this crop — the table's later sections continue on following pages, and the caption is cut off above the top rule. Verification: every count column sums exactly to its printed total — Number eligible to vote 582,212; Total elections 8,103; AFL-CIO 3,170; Teamsters 1,364; Other national 320; Other local 141; No representative 3,108. The cumulative-percent column also agrees with the running sum of the percent-of-total column throughout. This confirms "3,000-9,999" / Number eligible to vote, which images as "16, 15C" with a degraded final glyph, is 16,150. Doubtful percent cells (read as printed; each differs by 0.1 from the value implied by its own column total, so it is either an original rounding slip or a misread glyph): "50-59" and "200-299" / Other local unions, Percent by size class, read 7.2 (10/141 = 7.1); "80-89" and "90-99" / Other local unions, Percent by size class, read 2.9 (4/141 = 2.8); "200-299" / Elections in which no representative was chosen, Percent by size class, read 4.2 (127/3,108 = 4.1); "2,000-2,999" / AFL-CIO unions, Percent by size class, read 0.2 (4/3,170 = 0.1), though the adjacent "3,000-9,999" cell is clearly a different glyph, 0.1. Cells shown as a dash rule ("------") are transcribed as empty: the cumulative-percent cell of the "Total RC & RM elections" row, the percent cells accompanying a zero count in "160-169", "500-599", "2,000-2,999" and "3,000-9,999", and the percent-of-total plus all five percent-by-size-class cells of "10,000 and over". Printed zeros in those rows are kept as 0.

DECERTIFICATION ELECTIONS (RD)" is printed centred in caps above the table's top rule; I have kept it as a label-only section row at the head of the body, but a reader who treats it as part of the caption should drop that row. Decimal points: in this 1-bit scan the period in the percent columns is often lost, so values print as "20 8", "100 0". They are decimal fractions (the period survives in "83.7" and "100. 0"), and I have written them as 20.8, 100.0, etc. No digits were added or removed. Column 10 (the percent column paired with the all-zero column 9) carries only dash rules in every row including the total, so it is empty throughout; column 9 is a printed 0 in every row. In row "30-39", column 11 reads "0-": the 0 is the value and the hyphen is the first stroke of the leader dashes running into column 12. No value was computed or corrected, but as a check on column placement every column reproduces its own arithmetic exactly: columns 1, 2, 5, 7, 11 and 13 sum to the printed totals 10,510 / 221 / 45 / 18 / 1 / 157; percent columns 3, 6, 8 and 14 each sum to 100.0; and column 4 is the running sum of column 3 (e.g. 88.7 + 1.5 = 90.2, confirming the doubtful "1 5" in row 90-99 as 1.5 rather than 1.4). A few printed percentages differ by 0.1 from the raw quotient (13.4 for 6/45, 15.7 for 7/45, 11.2 for 5/45, 22.1 for 4/18, 2.6 for 4/157); these are as printed and are what make each column total exactly 100.0.
